# pairwise-vehicle-mount

角色跳上吉普车后视角跟着车一起抖，摄像机父节点被挂到载具上，悬挂的物理抖动直接传给了相机；下车时角色继承了载具的速度，站着就往前滑；载具与角色的碰撞体在挂载后没有互相忽略，角色被自己的车顶飞；上下车动画用根运动位移，模型位移被应用两次，角色陷进座椅；驾驶员切换座位时父子关系重建，角色的局部变换没重新计算，瞬间弹到车外；载具被摧毁时挂载点销毁，角色跟着一起被删除；多人同车时乘客位置按序号写死，中间的人下车后后面的座位全错位；上下车在高速时禁用，但判定用的是上一帧速度，撞墙前一帧仍能上车；载具网络同步只同步载具根节点，乘客的相对位置在客户端各自积分，过弯时人飘出车外；下车点被占用时没有后备位置，角色卡在车里出不来。gameplay/vehicle_mount.py 是核心，tests/test_vehicle_mount.py 15个红。要修的是：相机独立减震；下车清速度；挂载期忽略互碰；根运动只应用一次；重建世界变换；销毁先卸载；座位按 ID；用当前速度判定；同步乘客局部；后备下车点。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
